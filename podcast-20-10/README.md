# Podcast 20-10 · AxsPlano & SDA

Podcast ngắn gửi lời chúc ngày **Phụ nữ Việt Nam 20/10** từ team **AxsPlano & SDA**, kèm hình ảnh trao quà trong văn phòng.

## Mở trang

Mở file `index.html` trong trình duyệt, hoặc chạy server local:

```bash
cd podcast-20-10
python3 -m http.server 8080
```

Sau đó vào `http://localhost:8080`.

## Nội dung

- Audio TTS tiếng Việt (~1 phút 19 giây): `audio/podcast-full.mp3`
- 5 phần lời chúc đồng bộ với slideshow ảnh
- Hình ảnh team: `images/web/`

## Chỉnh sửa kịch bản

Sửa `script.json`, rồi tạo lại audio bằng `edge-tts` nếu cần.
